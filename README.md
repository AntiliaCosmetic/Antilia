# Antilia Cosmetics POC

This is a high-fidelity, dual-portal React Proof of Concept for Antilia Cosmetics, a premium skincare brand.

## How to Run

### 1. Prerequisites
Ensure you have [Node.js](https://nodejs.org/) installed on your system.

### 2. Installation
Open your terminal in the `Antilia` directory and run:

```bash
npm install
```

### 3. Start Development Server
To launch the application locally, run:

```bash
npm run dev
```

The application will be available at `http://localhost:5173/Antilia/`.

## Key Features
- **Customer Portal**: Luxury "Silk White" landing page, clinical skincare catalog, and glassmorphic checkout.
- **Admin Portal**: Operational command center with sales analytics and inventory management.
- **Tech Stack**: Vite, React, Framer Motion, Lucide Icons, Vanilla CSS.
